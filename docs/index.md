# Substrate documentation

**Last reviewed:** 2026-10-03. Re-read when the documentation structure changes.

Substrate aims to carry permitted memories, skills, and agent definitions between coding
harnesses. This checkout provides the bootstrap foundation. The product runtime is future
work; agreed architecture is documented separately from implemented behavior.

Start with [getting started](getting-started.md) to run the current executable, then read the
[development guide](development.md) for verification and previews. The
[first usable release](product/first-release.md) defines the next product evidence.

The product framing explains the [problem](product/problem.md), [vision](product/vision.md),
[positioning](product/positioning.md), and [non-goals](product/non-goals.md).
[Architecture decisions](architecture/index.md) cover deployment, artifact policy, retrieval,
and reconciliation. The [bootstrap plan](plans/bootstrap.md) records the scope of this foundation.
